# Skeleton-3d-camera
# 🎥 VisionX AI — Smart Gesture & Skeleton Tracking Camera

VisionX AI is a powerful Python-based AI camera application that uses Computer Vision and Artificial Intelligence to understand human movements, recognize hand gestures, track body motion, and generate a real-time 3D skeleton model.

Built using Python, OpenCV, MediaPipe, and AI-powered tracking systems.

---

# 🚀 Features

## ✋ Hand Gesture Recognition

Control applications and interact with your computer using hand signs and gestures.

* Detect fingers in real time
* Gesture-based controls
* Swipe detection
* Volume & media control
* Virtual mouse support

---

## 🧠 AI Motion Tracking

Track full-body movement using advanced pose estimation.

* Real-time body tracking
* Human movement analysis
* AI pose detection
* Fitness & activity tracking

---

## 🦴 Real-Time 3D Skeleton Generation

Generate a live animated 3D skeleton from camera input.

* Full body skeleton mapping
* Joint tracking
* Real-time bone movement
* Motion visualization

---

## 🎮 Gesture Controlled Media System

Use your hands to control videos and media.

Examples:

* ✋ Pause video
* 👉 Skip video
* 👌 Volume control
* 👋 Play/Pause gestures

---

## 📷 Smart AI Camera

Advanced camera utilities powered by AI.

* Face detection
* Object tracking
* Motion detection
* AI-powered camera filters

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Abdullahzahoor/Skeleton-3d-camera.git
cd visionx-ai
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
